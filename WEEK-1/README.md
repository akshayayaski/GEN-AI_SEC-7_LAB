
# Week 1 – First LLM API Call

## Aim
To connect a Python program with a Large Language Model (LLM) using an API and generate responses from user prompts.

## Requirements
- Python 3.14 or above
- VS Code
- OpenAI API Key or Gemini API Key
- Internet connection

## 1. Open Project Folder
Open the existing `week1-llm-call` folder in VS Code.

Open Terminal → New Terminal.

## 2. Activate Virtual Environment

If using the existing virtual environment:

```powershell
..\.venv\Scripts\Activate.ps1
```

## 3. Install Required Packages

**For OpenAI:**
```bash
python -m pip install openai python-dotenv
```

**For Gemini:**
```bash
python -m pip install google-genai python-dotenv
```

## 4. Create API Key File

Create a file named `.env` in the project folder.

For OpenAI:
```env
OPENAI_API_KEY=your_api_key
```

For Gemini:
```env
GEMINI_API_KEY=your_api_key
```

Never share your API key publicly.

## 5. Create .gitignore

Create a `.gitignore` file and add:

```gitignore
.env
.venv/
__pycache__/
.pytest_cache/
```

## 6. Create main.py

**OpenAI Code:**

```python
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

api_key = os.getenv("OPENAI_API_KEY")

if not api_key:
    raise ValueError("API key not found!")

client = OpenAI(api_key=api_key)

response = client.responses.create(
    model="gpt-5.5",
    input="What is Artificial Intelligence? Explain in simple words."
)

print("\nLLM Response:")
print(response.output_text)
```

**Gemini Code (alternative):**

```python
import os
from dotenv import load_dotenv
from google import genai

load_dotenv()

api_key = os.getenv("GEMINI_API_KEY")

if not api_key:
    raise ValueError("Gemini API key not found!")

client = genai.Client(api_key=api_key)

response = client.models.generate_content(
    model="gemini-3.8-flash",
    contents="What is Artificial Intelligence? Explain in simple words."
)

print("\nLLM Response:")
print(response.text)
```

## 7. Run the Program

Save all files and execute:

```bash
python main.py
```

Expected output:
- LLM Response
- AI explanation generated by the selected model.

## 8. Experiment with Different Prompts

Try changing the prompt:

1. Explain Generative AI with two real-world examples.
2. What is a Large Language Model?
3. Differentiate AI, ML and Deep Learning.
4. Explain five applications of Generative AI.

Run the program again to observe different responses.

For Gemini:

2. Create a new repository named `Week1-First-LLM-API-Call`.
